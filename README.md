# Devopscourse

*Scratch repository used to practise Git basics while following a DevOps course.*

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Overview

This repository holds the working files from a hands-on Git exercise: creating a
repository, staging changes, and pushing a series of commits. It contains no
application code, build configuration, or automation.

It is kept public as a record of that exercise. If you are looking for a
DevOps project to run or learn from, this is not it.

## What this repository does not contain

Stated explicitly so no one goes looking:

- No source code in any language, and no dependency manifest.
- No build, test, or run commands — there is nothing to build or run.
- No CI workflows (`.github/workflows/` is absent).
- No Dockerfile, deployment manifests, or configuration.
